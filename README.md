# RYO

### What is RYO?

**RYO** (Resolve Your Occurrences) is an application built using Electron, designed to help companies manage and monitor their incidents more efficiently by offering advanced features and comprehensive control. RYO provides you with absolute control over your business, enabling complete management.

### Where are we now?

We are currently developing the concept and defining the foundations for what we want RYO to become. We are working on all the features we intend to implement to establish RYO as one of the best incident management (ticketing) systems.
